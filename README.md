# Pomodoro Timer ⌛

A clean and responsive Pomodoro Timer built using React.js and Tailwind CSS to help improve productivity and focus using the Pomodoro Technique.

## 🚀 Live Demo

🔗 https://pomodoro-timer-darw.vercel.app/

## ✨ Features

- ⏱️ 25-minute Pomodoro timer
- ☕ Short break session
- ▶️ Start / Pause functionality
- 🔄 Reset timer
- 🎨 Modern responsive UI
- ⚛️ Built with React Hooks
- 💨 Tailwind CSS styling

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- HTML5
- CSS3
